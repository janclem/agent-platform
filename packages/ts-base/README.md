# ts-base

Small, dependency-free TypeScript helpers for strings, JSON, SHA-256 hashing and JSON
HTTP clients with retries, shared by the platform's packages.

Adapted from Robbie Palmer's [`hq`](https://github.com/Robbie-Palmer/hq) `packages/ts-base`
(`strings`, `json`, `crypto` and `http` only) at commit `6c08a3b`, under the AGPL-3.0.
